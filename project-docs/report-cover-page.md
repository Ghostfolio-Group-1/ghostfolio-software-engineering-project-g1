## Vision

This project extends Ghostfolio, an open-source portfolio management platform, with four new capabilities: portfolio health and risk analysis, detailed tax metrics and calculations, upgraded performance charting, and a unified portfolio overview dashboard that ties all three together. Alongside these features, the team is migrating the frontend to a new React-based component architecture and moving the backend toward a modular, SOA-style structure. Iteration 1 focuses entirely on design, data modelling, and architecture — establishing precise specifications, data models, wireframes, and a populated backlog so that Iteration 2 is pure implementation.
