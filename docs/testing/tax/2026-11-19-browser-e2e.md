## Scope and expectations

The tests use the existing Playwright config and real Angular-to-React TaxWorkspace at `/en/portfolio/tax`. They listen to authenticated responses produced by the browser's existing API adapter; no route interception or frontend tax calculations are introduced. They check:

1. Empty synthetic user: FIFO-only lots, four tax tabs, live GET responses, empty states, UTC calendar-year selection.
2. Populated synthetic user: open/all lot filters and exact lot quantities, realized gains under FIFO and average cost with decimal-string parity, dividend withholding/null-net display, and yearly summary decimal/null parity for UTC 2026.

The users are the **existing** `demo-risk-empty` and `demo-risk-rich` synthetic fixtures from `scripts/seed-risk-demo-data.mts`. They must be seeded into the **same disposable database** used by the running Ghostfolio demo API. Never run the seed script against production or a shared database; it deliberately uses documented fixed demo login tokens.
